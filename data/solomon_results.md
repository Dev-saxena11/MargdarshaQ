# Solomon CVRPTW benchmark results

_Generated by `scripts/run_solomon_benchmark.py` on 2026-09-23 with `--max-iter 200 --seed 1`. Re-run it to reproduce every figure below._

Solomon's objective is hierarchical: fewest vehicles first, then shortest distance. A solution using more vehicles does not beat one using fewer, however short its routes are -- so the vehicle count is reported beside the distance rather than behind it.

A run that breaks a time window has no gap to report. Every published figure is feasible, and an infeasible solution is usually short *because* it skipped a window, so quoting its distance as a result would be backwards.
